# Anti-Slop Audit #001 (2026-11-22)

- **Scope**: `index.html`, `style.css`, `app.js`, `widgets.js`, `config.json`, `sources.json`, `admin.html`, `admin.js`
- **Contrast Summary**: Newly applied **Sage Green (`#257A54` / `#5BB98C`) + warm off-white (`#FCFBF8`) / low-glare dark (`#191C20`)** core pairs (**16 pairs**) **ALL PASS WCAG AA** (`4.54:1` to `15.27:1`), verified via `contrast-check.py`. Two legacy light-mode status badge pairs FAIL (item #1 below).

## HIGH (Hard Gate)

1. **[HIGH] R-25** — `style.css` (lines 14–17): Light mode `--live-text` (`#03B26C`) on `--live-bg` (`#E8F8F0`) is **2.52:1** (fails both 4.5:1 normal and 3.0:1 large), and `--warn-text` (`#F04452`) on `--warn-bg` (`#FFEEEE`) is **3.31:1** (fails 4.5:1 normal).
2. **[HIGH] R-39** — `index.html` & `app.js`: Document has no `<h1>` element after replacing the top hero with the bento dashboard, breaking page heading hierarchy.
3. **[HIGH] R-32** — `style.css` (line 1414): Only `.nav-btn` defines `:focus-visible`; interactive controls (`.tds-now-strip`, `.home-bento-card`, `.sheet-close`, `.carousel-nav-btn`, `.school-pill`, clickable widget cards) lack a consistent high-contrast focus indicator.
4. **[HIGH] R-03** — `style.css` (lines 503, 525, 1499): Mobile touch targets `.sheet-close` (`32×32px`), `.carousel-nav-btn` (`26×26px`), and `.carousel-dot` (`6×6px` / `18px`) are below the `44×44px` minimum tap area.
5. **[HIGH] R-39** — `widgets.js` (lines 165–186, 754–768): `attachHalfSheetTrigger` assigns `role="button"` to `<section>` cards that contain nested buttons/links, and the auto-rotating ticker (`setInterval`, `3000ms`) runs continuously without checking `prefers-reduced-motion: reduce` or offering a pause control.
6. **[HIGH] R-02** — `index.html` (lines 9, 16), `sources.json` (lines 59, 87, 219), `admin.js` (line 331): Forbidden em dash (`—`) appears in UI/meta copy (6 occurrences).
7. **[HIGH] R-17 / R-36 / R-38** — `index.html` (line 10), `sources.json` (lines 66, 94, 121, 145, 169, 193, 217): Unmeasured `"0.5초 만에"` speed claim in `og:description` and hardcoded sample `likes` counts (`94, 138, 112, 76, 65, 151, 88`) without a real source or placeholder label.
8. **[HIGH] R-40** — `widgets.js` (lines 266, 325, 475): Dynamically created `<img>` elements (`.blog-thumb-img`, `.article-cover-img`, carousel slide `<img>`) omit intrinsic `width`/`height` HTML attributes.
9. **[HIGH] R-27** — `app.js`: Empty states exist, but explicit loading and error recovery states (with cause and next action when `data.js` fails or is missing) are incomplete.
10. **[HIGH] R-37** — Workspace root: Missing `DESIGN.md` declaring brand identity, palette rationale, and explicit `ENERGY / RHYTHM / MOTION` dials.
